🔐 Information Security Lab Project

Welcome to CyberHouse

A secure operations center implementing Bell-LaPadula Mandatory Access Control, Role-Based Access Control (RBAC), and bcrypt password hashing — all in one Django application.

🚀 Get Started 🔑 Login
🔒

Bell-LaPadula Model

Mandatory Access Control enforcing No Read Up and No Write Down policies across three security levels: Unclassified, Confidential, and Secret.

👥

Role-Based Access Control

Three distinct roles — Admin, Analyst, and Viewer — each with unique permissions and security clearances enforced at every endpoint.

🔑

bcrypt Password Hashing

All passwords are hashed using bcrypt with 12 rounds of salt, making brute-force attacks computationally infeasible. No plaintext passwords stored anywhere.

📋

Audit Access Logs

Every access attempt — granted or denied — is logged with timestamp, IP address, user identity, and reason. Full accountability chain for forensic analysis.

⚡

Real-Time Policy Demo

Interactive demonstration showing exactly which documents each user can read or write, with live BLP policy decisions explained for every object.

🛡️

CSRF & Session Security

Django's built-in CSRF protection, secure session management, and middleware-enforced security policies guard every page and form submission.
