📚 Bell-LaPadula Model — Formal Definition
ss-property (No Read Up)
subject S can read object O iff
clearance(S) ≥ classification(O)
Prevents subjects from reading objects at higher security levels — stops upward information flow.
*-property (No Write Down)
subject S can write object O iff
clearance(S) ≤ classification(O)
Prevents subjects from writing to lower-level objects — stops downward information leakage.

# Bell-LaPadula enforcement in Python (Django)

def bell_lapadula_can_read(user, document):
"""Simple Security Property: No Read Up"""
return user.security_clearance >= document.security_level

def bell_lapadula_can_write(user, target_level):
"""Star Property: No Write Down"""
return user.security_clearance <= target_level
